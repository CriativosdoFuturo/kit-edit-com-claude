# Kit Edit com Claude Code

Kit do curso **Edit com Claude Code**, do **Trombino / Criativos do Futuro**: skills, decupagem
automática em português e animações com HyperFrames, para o Claude editar seus vídeos.

## 1. Instalar o kit e as skills (aula 03)

Na aba **Code** do app do Claude, mande este link junto com o prompt da aula:

**https://github.com/CriativosdoFuturo/kit-edit-com-claude/blob/main/INSTALAR.md**

O Claude cria a pasta **Documentos\Edit com Claude**, baixa o kit e prepara tudo.

**Conferir:** abra uma conversa nova no Claude (em qualquer pasta) e digite **/trombs**.
Aparecem todas as skills do curso juntas, como **/trombs-decupagem-pt**,
**/trombs-edit-video** e **/trombs-hyperframes**. As skills valem em qualquer conversa; os seus
projetos ficam em **Documentos\Edit com Claude\video-projects**.

## 2. Conectar o seu editor (aula 03)

| Editor | Link para mandar ao Claude |
|---|---|
| Adobe Premiere (Windows e Mac) | [INSTALAR-PREMIERE.md](./INSTALAR-PREMIERE.md) |
| DaVinci Resolve | https://github.com/samuelgursky/davinci-resolve-mcp |
| CapCut Windows | https://github.com/yabdulaziz2009-dev/capcut-mcp |
| CapCut Mac | https://github.com/drhema/mcp-cut |
| Final Cut Pro (Mac) | https://github.com/DareDev256/fcp-mcp-server |

Observações de cada editor: [COMPATIBILIDADE-EDITORES.md](./COMPATIBILIDADE-EDITORES.md).

## 3. HyperFrames (aula 06)

O HyperFrames é gratuito e já vem no kit. Na aula 06, o Claude prepara o motor de animação e faz um
teste de 8 segundos (Parte 2 do [INSTALAR.md](./INSTALAR.md)).

## Deu erro?

Continue na mesma conversa e escreva **Resolva**. Se o Claude não conseguir, peça: "me dá um passo a
passo para eu resolver". Se ainda assim não der, fale com o suporte do curso.
